# Askane Benchmark Suite (0-100 Score)

Пятикомпонентный кросс-версионный и кросс-языковой бенчмарк для оценки производительности Askane VM и сравнения с другими языками (Python, Node.js/Bun/Deno).

## Тесты и веса

| Тест | Файл | Вес в общем балле | Что проверяет |
| --- | --- | --- | --- |
| Игровой | [01_game.ask](01_game.ask) | 15% | 64 сущности, 280 кадров: коллизии, урон, обновление словарей |
| Инфографический | [02_infographic.ask](02_infographic.ask) | 15% | 600 строк в `json.stringify` / `json.parse`, 320 раундов агрегации |
| Математический | [03_math.ask](03_math.ask) | 20% | Решето до 18 000 (x24), тригонометрия `math` (60 000), модульная степень (20 000) |
| Визуальный | [04_visual.ask](04_visual.ask) | 15% | Программный 2D RGB-растеризатор 120x72 за 28 кадров |
| Скриптовой | [05_scripting.ask](05_scripting.ask) | **35%** | Рекурсия `fib(29) + fib(27)`, замыкания, `match` (120 000 вызовов), словари (75 000) |

Все 5 скриптов написаны на совместимом ядре языка (`let`, `fn`, `while`, `if`/`else`, `match`, `[]`, `#{}`, `clock()`, `math`, `json`), чтобы запускаться как на старых версиях (`0.10.2-fix+`), так и на `0.15.0+`.

Каждый тест проверяет точную контрольную сумму (`checksum`), одинаковую во всех версиях Askane и в портах для других языков (`bench/langs/py/`, `bench/langs/js/`). Балл считается по строгой шкале `min(100, 100 * TargetMs / MedianMs)` после 1 прогревочного и 3 основных прогонов (`TargetMs` калиброван примерно на `0.82 * Python 3.12`, чтобы Python 3.12 набирал около `82 / 100`, а быстрые JIT-рантаймы приближались к `100 / 100`).

## Запуск

Запустить все найденные версии Askane (`bench\*.exe`, `bench\versions\*.exe`, `.\askane.exe`) и доступные сторонние языки (`python`, `node`, `bun`, `deno`):

```powershell
.\bench\run_bench.ps1
```

Сырые времена всех прогонов:

```powershell
.\bench\run_bench.ps1 -ShowRaw
```

Только Askane без сторонних языков:

```powershell
.\bench\run_bench.ps1 -SkipLanguages
```

Выборочный список бинарников:

```powershell
.\bench\run_bench.ps1 -Binaries .\bench\versions\askane-0.13.0.exe, .\askane.exe
```
